JavaScript: синтаксис і DOM

JavaScript додає сторінці поведінку: може реагувати на події, змінювати HTML-елементи та оновлювати їхній вміст без перезавантаження.

Змінні, функції та події

const оголошує значення, яке не перепризначається, let — значення, яке можна змінювати. Функцію можна викликати після події, наприклад натискання кнопки. 

const button = document.querySelector("#change-message");
const message = document.querySelector("#demo-message");

function changeMessage() {
  message.textContent = "DOM оновлено JavaScript!";
  message.classList.toggle("is-highlighted");
}

button.addEventListener("click", changeMessage);

Натисніть кнопку, щоб змінити цей елемент сторінки.

Знаходимо елементи й змінюємо DOM

querySelector() знаходить елемент за CSS-селектором. Властивість textContent змінює текст, а classList — його CSS-класи. 

const heading = document.querySelector("h2");
heading.textContent = "Новий заголовок";
heading.classList.add("is-highlighted");

Приклад вище змінює саме повідомлення в попередньому блоці. Спробуйте кілька разів натиснути кнопку й перевірити результат.

Менше повторень: дані та цикл

Замість копіювати однаковий HTML для кожного пункту, зберігаємо дані в масиві й один раз створюємо елемент у циклі. 

const topics = ["DOM", "Події", "Масиви"];

for (const topic of topics) {
  const item = document.createElement("li");
  item.textContent = topic;
  list.append(item);
}

topics.push(topicName);
const index = topics.indexOf(topicName);
if (index !== -1) topics.splice(index, 1);

    Навчальна демонстрація шифрування даних

    Web Crypto API шифрує текст алгоритмом AES-GCM за допомогою випадкового ключа й одноразового вектора ініціалізації. У цій демонстрації ключ існує лише в пам'яті вкладки: дані нікуди не надсилаються й не зберігаються.

    Вводьте лише тестовий текст — не справжній пароль, платіжні дані чи особисту інформацію. Це навчальний приклад, а не захист для виробничого застосунку. 

    const key = await crypto.subtle.generateKey(
  { name: "AES-GCM", length: 256 },
  false,
  ["encrypt", "decrypt"],
);
const iv = crypto.getRandomValues(new Uint8Array(12));
const ciphertext = await crypto.subtle.encrypt(
  { name: "AES-GCM", iv },
  key,
  new TextEncoder().encode(text),
);

    Розшифрований текст

    У реальному сайті передавайте дані через HTTPS. Для збереження конфіденційних даних на сервері ключами керують на сервері або в спеціальному сховищі ключів. Паролі не шифрують для подальшого розшифрування — їх зберігають як стійкі хеші, наприклад Argon2id. Шифрування лише у браузері не захищає від шкідливого коду на пристрої користувача.

    Безпека в інтернеті

    Базові звички допомагають захищати акаунти, пристрої та персональні дані під час роботи в інтернеті.

    • Перевіряйте адресу сайту. Перш ніж вводити пароль або платіжні дані, перевірте домен і використовуйте HTTPS.
    • Використовуйте унікальні паролі. Менеджер паролів допомагає не повторювати пароль на різних сайтах.
    • Увімкніть багатофакторну автентифікацію. Використовуйте passkeys або застосунок-автентифікатор, де це доступно.
    • Остерігайтеся фішингу. Не відкривайте підозрілі вкладення й не повідомляйте коди підтвердження іншим людям.
    • Оновлюйте програми та пристрої. Встановлюйте оновлення з офіційних джерел і переглядайте дозволи застосунків.
    • Бережіть персональні дані. Не публікуйте конфіденційну інформацію та створюйте резервні копії важливих файлів.
    • Не довіряйте замочку як гарантії чесності. HTTPS шифрує з'єднання, але сам по собі не підтверджує, що сайт надійний.

    Збереження й читання даних у JSON

    JSON — формат структурованих даних, а не база даних. Ця форма надсилає запис локальному Node.js-серверу: сервер додає його у файл data/notes.json і повертає список записів. Кнопка нижче повторно завантажує дані з цього файла через API. Кожен запис можна видалити окремою кнопкою. 

    const response = await fetch("/api/notes", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ title, text }),
});

const notes = await fetch("/api/notes").then((result) => result.json());

await fetch(`/api/notes/${noteId}`, { method: "DELETE" });
