Корисні CSS-ресурси

Добірка офіційних сайтів, де можна знайти документацію, готові компоненти та ефекти для frontend-проєктів. Перед використанням перевіряйте умови ліцензії, сумісність і доступність компонентів.

CSS-фреймворки

Bootstrap

Популярний набір адаптивної сітки, CSS-компонентів і JavaScript плагінів. Підійде для швидкого створення типових інтерфейсів.

Tailwind CSS

Utility-first CSS-фреймворк: стилі компонуються з невеликих класів прямо в розмітці.

Bulma

CSS-фреймворк на Flexbox із готовими класами для сіток, форм, кнопок та інших поширених елементів.

Foundation

Адаптивний frontend-фреймворк із сіткою та інструментами для створення сайтів і вебзастосунків.

Бібліотеки готових UI-компонентів

daisyUI

Плагін для Tailwind CSS із семантичними класами компонентів, темами та готовими стилями.

shadcn/ui

Колекція компонентів для React, які додають у власний проєкт і надалі редагують у його кодовій базі.

Material UI (MUI)

Бібліотека React-компонентів, реалізованих у стилі Material Design і придатних для налаштування.

Uiverse

Спільнота з готовими UI-елементами та анімаціями на CSS, які можна переглядати й адаптувати для своїх проєктів.

21st.dev

Каталог і платформа для пошуку та використання сучасних React-компонентів у frontend-інтерфейсах.

Анімації та візуальні ефекти

Animate.css

Готові CSS keyframe-анімації, які можна швидко застосувати до HTML-елементів.

AOS

Animate On Scroll — бібліотека для анімації елементів під час прокручування сторінки.

Hover.css

Колекція CSS-ефектів наведення для посилань, кнопок, логотипів та інших елементів.

Motion

Бібліотека анімації для JavaScript і популярних UI-фреймворків; раніше була відома як Motion One.
