CSS: наочні уроки

CSS описує вигляд HTML-елементів. Змінюйте правила у прикладах і спостерігайте, як змінюється оформлення.

Селектори

Селектор обирає елементи, до яких застосовуються стилі. Наприклад, .demo-note обирає елемент за класом, а strong — за назвою тегу. 

.demo-note {
  color: #1d4ed8;
}

.demo-note strong {
  text-decoration: underline;
}

Цей абзац має клас demo-note, а цей текст підкреслений селектором strong.

Кольори та фон

Властивості color і background-color задають колір тексту та фону. 

.color-demo {
  color: #fff;
  background-color: #0f766e;
}
Білий текст на кольоровому тлі

Типографіка

CSS керує шрифтом, розміром, товщиною та інтервалом між рядками. 

.type-demo {
  font-family: Georgia, serif;
  font-size: 1.4rem;
  line-height: 1.6;
}

Інший шрифт, розмір і висота рядка

Box model: відступи та рамка

Кожен елемент — прямокутна область. padding додає внутрішній відступ, border — рамку, а margin — зовнішній простір. 

.box-demo {
  padding: 16px;
  border: 3px solid #7c3aed;
  margin: 12px 0;
}
Вміст блоку з рамкою та відступами

Рамки, заокруглення й тіні

border-radius заокруглює кути, а box-shadow додає тінь. 

.card-demo {
  border: 1px solid #cbd5e1;
  border-radius: 12px;
  box-shadow: 0 6px 16px rgb(15 23 42 / 12%);
}
Картка із заокругленням і тінню

Flexbox

display: flex розташовує елементи в ряд або колонку. gap задає відстань між ними. 

.flex-demo {
  display: flex;
  flex-wrap: wrap;
  gap: 12px;
}

CSS Grid

Grid створює сітку рядків і колонок. Тут кожна колонка має однакову ширину. 

.grid-demo {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
}

Стани та взаємодія

Псевдокласи, наприклад :hover і :focus, стилізують елемент під час взаємодії з ним. 

.interactive-demo:hover {
  background-color: #1d4ed8;
}

.interactive-demo:focus-visible {
  outline: 3px solid #93c5fd;
}

Адаптивність і медіазапити

Медіазапит застосовує стилі лише за певної умови, наприклад коли ширина екрана не перевищує 600 пікселів. 

@media (max-width: 600px) {
  .responsive-demo {
    font-size: 0.9rem;
    padding: 12px;
  }
}
На вузькому екрані цей блок змінить розмір тексту та відступи.

Галерея зображень

CSS Grid розташовує зображення різної ширини, а aspect-ratio задає їм різні пропорції. Властивість object-fit: cover заповнює рамку зображенням і обрізає зайве. Для прикладу використано одне локальне фото з різними пропорціями відображення; у власній галереї вкажіть різні файли у src. 

.image-gallery {
  display: grid;
  grid-template-columns: repeat(4, minmax(0, 1fr));
  gap: 12px;
}

.gallery-item--wide {
  grid-column: span 2;
}

.image-gallery img {
  width: 100%;
  object-fit: cover;
}

.gallery-image--wide { aspect-ratio: 16 / 9; }
.gallery-image--portrait { aspect-ratio: 3 / 4; }
.gallery-image--square { aspect-ratio: 1; }

Випадаюче меню

Елемент <details> створює меню, яке відкривається натисканням. Його можна використовувати без JavaScript. 

.dropdown[open] .dropdown-menu {
  display: grid;
}

.dropdown-menu a:hover {
  background: #dbeafe;
}

Navigation bar

Навігаційну панель можна зібрати з Flexbox і посилань. Властивість justify-content розподіляє елементи по ширині. 

.demo-navbar {
  display: flex;
  flex-wrap: wrap;
  justify-content: space-between;
  gap: 8px;
}

Порядок шарів: z-index

Для елементів з позиціонуванням z-index визначає, який шар буде поверх іншого. Більше значення розміщує елемент вище. 

.layer {
  position: absolute;
}

.layer-back { z-index: 1; }
.layer-front { z-index: 2; }

Стилізація таблиць

CSS допомагає оформити межі й відступи комірок, а псевдоклас :nth-child(even) додає чергування кольору рядків. 

.styled-table {
  width: 100%;
  border-collapse: collapse;
}

.styled-table tbody tr:nth-child(even) {
  background: #eff6ff;
}
Властивість Що змінює
border-collapse Об'єднує межі комірок
padding Додає внутрішні відступи
:nth-child(even) Обирає парні рядки

Position

position: relative залишає елемент у звичайному потоці, але створює точку відліку для дочірнього елемента з position: absolute. 

.position-demo {
  position: relative;
}

.position-badge {
  position: absolute;
  top: 12px;
  right: 12px;
}
