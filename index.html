Text

Текст на сторінці розміщують в абзацах <p>. Наприклад, важливу думку (<strong>) можна виділити жирним, а інтонаційний наголос (<em>) — курсивом.

Також можна позначити важливий фрагмент (<mark>) або показати фрагмент коду (<code>).

Links

Посилання ведуть на інші сторінки або розділи поточної сторінки.

Image

Зображення додають тегом <img>. Атрибут alt описує його для доступності.

Page Parameters

Мова документа задається атрибутом lang у тезі <html>. Кодування та масштаб сторінки налаштовують через елементи <meta> у блоці <head>. 

<html lang="uk">
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">

Tables

Таблиці показують структуровані дані: рядки створюють через <tr>, заголовки — через <th>, комірки — через <td>.

Тег Призначення
<tr> Рядок таблиці
<td> Звичайна комірка

JavaScript

Head

У блоці <head> вказують SEO-метадані: змістовну назву сторінки та короткий опис для пошукових систем. Open Graph метадані задають заголовок і опис під час поширення посилання в соцмережах. 

<head>
  <title>HTML Lessons — уроки HTML</title>
  <meta name="description" content="Наочні приклади HTML для навчання.">
  <meta property="og:title" content="Уроки HTML">
  <meta property="og:description" content="Вивчаємо HTML на прикладах.">
  <link rel="icon" type="image/png" href="src/favicon.png">
</head>

Щоб змінити іконку вкладки, замініть файл src/favicon.png на власну іконку або вкажіть шлях до іншого файлу в атрибуті href елемента <link rel="icon">.

Responsive Design

Адаптивний дизайн підлаштовує розміри та розташування елементів під ширину екрана. Медіазапити допомагають змінювати стилі для мобільних пристроїв. 

@media (max-width: 600px) {
  .card {
    padding: 12px;
  }
}

Form

Форма збирає дані від користувача. Атрибути type, name і required визначають тип та правила введення.

Media

Елементи <audio> і <video> додають на сторінку звук і відео. Вкажіть файл у src або в дочірньому елементі <source>.

Аудіо з файлу src/music.mp3 через атрибут src:

Той самий аудіофайл через вкладений елемент <source>: 

<audio controls src="src/music.mp3"></audio>

Те саме відео через вкладений елемент <source>: 

<video controls>
  <source src="src/video.mov" type="video/quicktime">
</video>
