# HTML-Lessons-HTML

Навчальний сайт для наочного вивчення HTML. На прикладах можна побачити,
як працюють HTML-теги та атрибути, як вони впливають на вміст сторінки
і як семантична розмітка допомагає структурувати інформацію.

Сайт містить окремі уроки з прикладами тексту, посилань, зображень, таблиць,
кнопок, iframe, форм, мультимедіа та інших HTML-елементів. Його можна
використовувати під час пояснення матеріалу учням і для самостійного
дослідження елементів розмітки.

Сторінка [css.html](./css.html) містить наочні приклади CSS: селектори,
кольори, типографіку, модель блоків, Flexbox, Grid, галерею зображень різних
пропорцій, випадаюче меню, навігаційну панель, `z-index`, стилізацію таблиць,
позиціонування, стани елементів та адаптивність. Усі навчальні сторінки мають
спільну шапку для навігації.

Сторінка [js.html](./js.html) показує основи синтаксису JavaScript, керування
DOM, повторне використання коду за допомогою функцій і циклів, модальні вікна
та збереження нотаток у JSON-файл через локальний сервер. У списку тем можна
додавати назву й видаляти тему за назвою; нотатки у JSON можна видаляти окремо.

Стилі організовані окремо: [base.css](./base.css) містить спільне оформлення,
а [html.css](./html.css), [css.css](./css.css) і [js.css](./js.css) — стилі
відповідних сторінок.

## Запуск сайту

Для перегляду уроків і збереження нотаток запустіть із кореневої папки проєкту:

```sh
node server.js
```

Потім відкрийте <http://127.0.0.1:3000>. Нотатки зберігаються у
`data/notes.json`. Файл JSON тут демонструє просте локальне сховище, а не
повноцінну базу даних. Зупиніть сервер комбінацією `Ctrl+C`.
