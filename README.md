# HTML-Lessons-HTML

Навчальний сайт для наочного вивчення HTML. На прикладах можна побачити,
як працюють HTML-теги та атрибути, як вони впливають на вміст сторінки
і як семантична розмітка допомагає структурувати інформацію.

Сайт містить окремі уроки з прикладами тексту, посилань, зображень, таблиць,
кнопок, iframe, форм, мультимедіа та інших HTML-елементів. Його можна
використовувати під час пояснення матеріалу учням і для самостійного
дослідження елементів розмітки.
